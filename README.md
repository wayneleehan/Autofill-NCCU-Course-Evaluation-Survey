# Autofill NCCU Course Evaluation Survey(Tampermonkey Script)

自動填答 **國立政治大學NCCU** 的「教學意見調查」與「學生自評核心能力問卷」，支援中／英授課動態判斷。

---

## 功能特色

- **學習狀況**：缺課、預習、複習自動填(從未缺課、預習複習三小時)
- **教學成效共同題**：隨機選擇非常同意（50%）、同意(30%)、普通(20%) 
- **英文授課相關題目**：一律選第一個，曾修習英文授課課程數為4以上
- **關鍵能力題**：隨機選擇提升 80%~100%（50%）、60%~80%(30%)、40%~60%(20%) 
- **彈性授課題**：  **第一題須自填**，其餘自動選擇非常滿意＆無意見
- **核心能力自評**：將所有下拉題目一律設為最高分 5
- **多選題型支援**（新功能）：支援問卷中隱藏的複選題（如意見回饋等），可自訂勾選特定順序的選項（例如：前兩個、第七與第八個）。
- **終極防漏填掃描機制**（新功能）：填答完成後會自動執行動態掃描，若發現學校系統因動態更新而多出「未定義在腳本中」的全新單選題號，腳本會自動勾選第一個選項進行保底，確保 100% 順利送出。

## 安裝方式

1. 在 Chrome / Firefox （Chromium目前不可用）安裝 [Tampermonkey](https://www.tampermonkey.net/)。  
2. 點擊 Tampermonkey 圖示 → **新增腳本** → 將*nccu-auto-fill.user.js*貼入並儲存

    **務必要把extension中的developer mode 開啟！！！**  

3. 前往 NCCU 問卷頁面，校務資訊系統 → 學生資訊系統 → 學術服務→ 本學期教學意見調查，點選課程問卷（會自動幫你填答），檢查後即可送出。


## 自訂與調整
- 隨機分布：可修改 `Math.random()` 加權邏輯，或統一改成指定分數。

- **欄位與多選對應**：若多選題（如 `M31`, `M32`, `M59`）的勾選偏好有變，可直接在腳本中修改 `checkMultiple("Mxx", ["1", "2"])` 後方陣列的代號。

- 延遲時間：若網頁載入較慢，可將 `setTimeout(..., 300)` 中的延遲毫秒數調大。

- **動態輪詢機制（取代固定延遲）**：舊版使用固定延遲 `setTimeout(..., 300)` 容易因網路慢或系統未載入完成而失效。新版已全面升級為 `setInterval` 動態輪詢機制（每 200ms 偵測一次），會主動等待學校系統內嵌框架（iframe 中的 `mainFrame`）渲染完畢後才一秒內瞬間填答，不再需要手動調整延遲時間。

## 注意事項
- ***僅供校內快速填答測試與示範，請務必遵守校方問卷填答規範。***

- 若問卷結構大幅調整，需同步更新此腳本。

## 常見問題與除錯 (Troubleshooting)

### Q1. 為什麼打開瀏覽器開發者工具（F12）後，網頁會卡住或顯示 "Paused in Debugger"？
* **原因**：政大校務系統的前端程式碼中內嵌了 `debugger;` 指令。當你開啟 F12 的狀態下執行跳轉，瀏覽器會強制暫停所有 JavaScript 運作，這會導致自動填答腳本也跟著一起停擺。
* **解決方法**：
  1. **最簡單的方法**：直接**關閉開發者工具 (F12)**，`debugger;` 指令就不會觸發，重新整理網頁（F5）腳本就會在背景默默填完。
  2. 如果想開著 Console 觀察，可在 DevTools 的 **Sources** 面板右上角，點擊 **"Deactivate breakpoints"（一條斜線劃過箭頭的圖示，快捷鍵 `Ctrl + F8` / `Cmd + F8`）**，然後按下播放鍵（▶ / `F8`）釋放網頁，之後瀏覽器就會無視該指令。

### Q2. 為什麼以前可以跑，這學期突然有些格子空著沒填？
* **原因**：學校系統每學期可能會微調題號（例如動態增減 `S54`, `S58`, `S60` 等），或者部分動態產生的多選題（`type="checkbox"`）未被舊版腳本捕捉。
* **解決方法**：新版腳本已加入「多選題支援」與「終極防漏填掃描機制」，能自動幫未知的單選新題勾選第一個選項。若仍有特殊題型漏填，可在 Console 切換至 `mainFrame` 環境並執行以下語法獲取最新代號：
